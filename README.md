## Before publishing
1. Replace `91XXXXXXXXXX` in `app.js` with your business WhatsApp number (country code + number, digits only).
2. Replace demo/remote images with properly licensed, destination-accurate photos. Current Unsplash images are placeholders and may not all depict the named destination accurately.
3. Confirm tour itineraries, prices, inclusions, permits and travel fees before publishing them as offers.
4. Add the official business phone, email, address, privacy policy and terms.
5. This is a static front-end starter. It does not yet include an admin login, database, booking storage or live availability. Those require a separately configured backend such as Supabase.
6. Deploy to a new GitHub repository, then configure `takinholidays.in` under the hosting provider's custom-domain settings and set DNS records there.
